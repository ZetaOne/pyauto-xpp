Run pyauto-xpp from this page

The editor sends your code to pyauto-xpp on your own computer (XPPAUT and its AUTO, at full native speed, your files on your disk). That needs a one-time install, done from here.

First time on this computer: install

Open Terminala terminal, paste this line and press Enter:

curl -LsSf https://zetaone.github.io/pyauto-xpp/editor/install.sh | sh

then double-click install-pyxpp.bat (Windows asks once whether to run a downloaded file: More info → Run anyway). Or paste this into PowerShell:

powershell -ExecutionPolicy ByPass -c "irm https://zetaone.github.io/pyauto-xpp/editor/install.ps1 | iex"
  1. It finds out what your computer is (system, processor) and installs only what is missing: uv, a Python for pyauto-xpp in its own folder ~/.pyxpp, and the pyauto-xpp built for your machine. No administrator rights.
  2. It registers pyxpp:// links, so this page can start pyauto-xpp next time with one click.
  3. It starts pyxpp serve and this page connects by itself. Your files go to ~/pyxpp-work.

Your browser may ask whether this page may connect to apps on your device or local network: allow it (the page talks only to 127.0.0.1, this computer).

Already installed

Or in a terminal: ~/.pyxpp/env/bin/pyxpp start (Windows: %USERPROFILE%\.pyxpp\env\Scripts\pyxpp start). If this page cannot reach it (some browsers block a secure page from talking to http://127.0.0.1), open the same editor from your computer: http://127.0.0.1:8790/.
