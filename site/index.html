pyauto-xpp

XPPAUT 8.2 and its AUTO as a Python module. Every XPP button is a Python call, AUTO runs from Python (also for delay equations), and models can be written in Python. No X11, no windows to click.

  • 70 tutorials
  • Linux and macOS wheels, Python 3.9-3.15

Quick start #

Three ways to get it: nothing to install (Binder), one tool that sets up everything (pixi), or pip.

curl -fsSL https://pixi.sh/install.sh | bash   # once, then open a new terminal
git clone https://github.com/ZetaOne/pyauto-xpp && cd pyauto-xpp
pixi run lab        # JupyterLab with the tutorials opens in your browser
pixi run scripts    # every tutorial script, one line each
pixi run test       # the package's tests
python -m pip install pyauto_xpp-0.2.0-cp312-cp312-win_amd64.whl   # the wheel for your Python, from Releases
python -m pip install matplotlib jupyterlab ipywidgets plotly anywidget jupytext
python tools/jupytext_default.py   # .py scripts open as notebooks
jupyter lab         # in the unzipped repository folder

On Windows use the prebuilt wheel (Releases) or Binder: building from source there needs the MinGW-w64 compiler (MSYS2), not Microsoft's.

The first run downloads Python and the packages and builds XPP's C library; after an update only what changed is downloaded again. No git? Take the .zip, unzip it and run pixi run lab in that folder.

Download the wheel for your system and Python version from the Releases page (see Downloads below), then:

python -m pip install pyauto_xpp-0.2.0-cp312-cp312-<your system>.whl
python -m pip install matplotlib    # for the figures in the tutorials
python -c "import pyxpp; print(pyxpp.__file__)"

cp312 is Python 3.12: pick the wheel whose tag matches python --version (cp39 to cp315). Linux x86_64 and ARM (glibc 2.28+), macOS Apple Silicon (11+) and Intel (10.9+ up to Python 3.11, 10.13+ for 3.12-3.13, 10.15+ for 3.14-3.15), Windows x86_64.

Builds XPP's C library on your computer, so it needs a C compiler (gcc or clang).

git clone https://github.com/ZetaOne/pyauto-xpp && cd pyauto-xpp
python -m pip install .            # or: pip install ".[plot]" for matplotlib too
python -m pytest -q tests          # optional: the tests (needs pytest)

Runs JupyterLab with pyauto-xpp and all tutorials on mybinder.org, in your browser. It starts in a minute or two; edits are not kept, so download what you change.

A first look

import pyxpp
from pyxpp.builder import ModelBuilder

mb = (ModelBuilder("fhn")
      .ode("v", "v-v^3/3-w+i").ode("w", "eps*(v+a-b*w)")
      .parameter(i=0.2, a=0.7, b=0.8, eps=0.08).initial(v=-1.2, w=-0.6))
m = mb.load()
tr = m.run(total=200)                         # Initialconds > Go
m.equilibrium({"v": -1.2, "w": -0.6})         # Newton + eigenvalues
m.run(total=300); m.run_last()
d = m.auto.run("i", start="steady", ds=0.01, parmin=0, parmax=2)   # AUTO
d.special("HB")

Tutorials #
