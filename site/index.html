pyauto-xpp

XPPAUT 8.2 + AUTO in Python GitHub

XPPAUT and its AUTO as a Python module: every XPP button is a Python call, AUTO runs from Python (including delay equations), and models can be written in Python. With 70 tutorials.

Try it in your browser (Binder) Download everything (.zip) Prebuilt packages (Releases)

Install on your computer

curl -fsSL https://pixi.sh/install.sh | bash      # once
git clone https://github.com/ZetaOne/pyauto-xpp && cd pyauto-xpp
pixi run lab        # JupyterLab opens in your browser
pixi run scripts    # all tutorial scripts, one line each
powershell -c "irm -useb https://pixi.sh/install.ps1 | iex"     # once
git clone https://github.com/ZetaOne/pyauto-xpp ; cd pyauto-xpp
pixi run lab
# Windows support of the C library is still being ported.

After an update, only what changed is downloaded again.
